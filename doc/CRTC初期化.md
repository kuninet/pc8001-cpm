# PC-8001 CRTC(μPD3301)初期化 — 80桁×25行テキスト

PC-8001 は表示制御に μPD3301、画面用 DMA に μPD8257(Ch2)を使う。VRAM(`0xF300`〜)を DMA で μPD3301 に転送して表示する。本書は CP/M の 80桁×25行テキスト表示に必要な ICW SCREEN FORMAT 値と初期化シーケンスをまとめる。

## I/O ポート

| ポート | 用途 |
|--------|------|
| `0x50` | μPD3301 パラメータ入出力(ICW SCREEN FORMAT / OCW パラメータ) |
| `0x51` | μPD3301 コマンド入出力(ICW / OCWn) |
| `0x40` | 表示制御。d3 = `/CLDS`(0 で表示有効) |
| `0x64` | μPD8257 Ch2 DMA アドレスセット(VRAM 先頭) |
| `0x65` | μPD8257 Ch2 ターミナルカウント+転送モード |
| `0x68` | μPD8257 モードセット |

## VRAM 構成(N-BASIC 互換)

- 先頭 `0xF300` 固定。
- 1 行 = 表示 80 バイト + アトリビュート 40 バイト(20 組 × 2 バイト)= **120 バイト**。
- 25 行 → (80 + 40) × 25 = **3000 バイト**(`0xF300`〜`0xFEB7`)。
- アトリビュートはトランスペアレント方式(文字エリアと属性エリアを分離。256 文字使用のため必須)。属性の詳細構造は [アトリビュート.md](アトリビュート.md) を参照。

## ICW SCREEN FORMAT 値(80桁×25行・200ライン)

各バイトの導出。`OUT (0x50)` に FORMAT1→5 の順で送出する。

### FORMAT1 = `0x4E`(画面構成・DMA 制御)
- d7 = C/B: `0` = DMA バーストモード(1 行分を一括 DMA)
- d6-d0 = H6-H0: 1 行の文字数。**n 文字には n−2 を設定** → 80−2 = 78 = `0x4E`
- → `0b0_1001110` = **`0x4E`**

### FORMAT2 = `0x18`(ブリンク・行数)
- d7-d6 = B1-B0: ブリンキング時間 `00`(カーソル 16 / アトリビュート 32)
- d5-d0 = L5-L0: 行数。**m 行には m−1 を設定** → 25−1 = 24 = `0b011000`
- → `0b00_011000` = **`0x18`**

### FORMAT3 = `0x67`(カーソル・ライン数/文字)
- d7 = S: `0` = 通常表示(1 行おきにしない)
- d6-d5 = C1-C0: カーソル表示モード `11` = ブリンキング有り・反転ブロックカーソル
- d4-d0 = R4-R0: 1 文字のライン数。**n′ には n′−1 を設定** → 200 ライン / 25 行 = 8 ライン/文字 → 8−1 = 7 = `0b00111`
- → `0b0_11_00111` = **`0x67`**

### FORMAT4 = `0xDE`(垂直帰線・水平帰線)
- d7-d5 = V2-V0: 垂直帰線幅。25 行モードは `110`(資料表記「7 行」)
- d4-d0 = Z4-Z0: 水平帰線幅。25 行モードは 32 文字 → Z 値 `11110`
- → `0b110_11110` = **`0xDE`**

### FORMAT5 = `0x53`(アトリビュート・特殊制御)
- d7-d6-d5 = AT1-AT0-SC: `010` = トランスペアレントカラー、特殊制御文字 有効
- d4-d0 = A4-A0: 最大アトリビュート数。**個数−1** → 20−1 = 19 = `0b10011`
- → `0b010_10011` = **`0x53`**

> 白黒運用にする場合は FORMAT5 を `0b000_10011` = `0x13`(トランスペアレント白黒)にする。PC-8001 はカラー機のため既定は `0x53`。

### まとめ

| パラメータ | 値 | 意味 |
|------------|-----|------|
| FORMAT1 | `0x4E` | 80 桁、DMA バーストモード |
| FORMAT2 | `0x18` | 25 行、ブリンク 00 |
| FORMAT3 | `0x67` | 8 ライン/文字、点滅反転ブロックカーソル |
| FORMAT4 | `0xDE` | 垂直帰線 7 行、水平帰線 32 文字(25 行・200 ライン) |
| FORMAT5 | `0x53` | トランスペアレントカラー、20 アトリ/行 |

> 20 行モードにする場合: FORMAT2 = `0x13`(20−1=19)、FORMAT4 = `0xBE`(垂直帰線 6 行=`101`、水平帰線 32 文字=`11110`)。

## DMA(μPD8257 Ch2)設定

VRAM `0xF300` から 3000 バイトをオートロードモードで CRTC へ転送する。

| ポート | 1 バイト目 | 2 バイト目 | 意味 |
|--------|-----------|-----------|------|
| `0x64` | `0x00` | `0xF3` | Ch2 DMA アドレス = `0xF300`(下位→上位) |
| `0x65` | `0xB7` | `0x4B` | ターミナルカウント = 2999(`0x0BB7`)+ DMA リードサイクル(Wr=1) |
| `0x68` | `0x84` | — | モードセット: AL=1(オートロード)+ EN2=1(Ch2 有効) |

- ターミナルカウント = 転送バイト数 − 1 = 3000 − 1 = 2999 = `0x0BB7`。
- `0x65` の 2 バイト目 = `(Wr=1 → d6) | (C13-C8)` = `0x40 | 0x0B` = `0x4B`(メモリ→デバイスのリードサイクル)。

## 初期化シーケンス

Enri's Home Page の手順に従う:

1. `OUT (0x51), 0x00` — **ICW: RESET**(パラメータ書き込み可能状態にする)
2. **DMA 設定**(μPD8257 Ch2):
   - `OUT (0x64), 0x00` / `OUT (0x64), 0xF3` — DMA アドレス `0xF300`
   - `OUT (0x65), 0xB7` / `OUT (0x65), 0x4B` — カウント 2999 + リードサイクル
   - `OUT (0x68), 0x84` — オートロード + Ch2 有効
3. **ICW SCREEN FORMAT 1〜5** を順に:
   - `OUT (0x50), 0x4E` / `0x18` / `0x67` / `0xDE` / `0x53`
4. `OUT (0x51), 0x43` — **OCW3: SET INTERRUPT MASK**(オートロード時 MN=1, ME=1 → `0b0100_0011`)
5. `OUT (0x51), 0x20` — **OCW2: START DISPLAY**(d5=1, DM=0 通常表示)
6. `OUT (0x40), <d3=0>` — `/CLDS` を 0 にして表示有効化(他ビットは CMT/BEEP 制御。実機 N-BASIC 既定に合わせる)

## 実装メモ

- 現状 `src/bios/bios.asm` の `BOOT_BODY` は `OUT (0x51), 0x00`(RESET)のみのスタブ。本書の手順 1〜6 を実装する。
- 値はすべて資料からの導出値であり、**実機 N-BASIC ROM の実値との照合(または実機表示確認)が必要**。特に FORMAT3(カーソル)・FORMAT5(カラー/白黒)・`0x40` の他ビットは実機(#39)で確定する。
- エミュレータ `emu/pc8001.py` は `0x50`/`0x51`/`0x40` を受理するが現状スタブ(`crtc_param`/`crtc_cmd` へ蓄積するのみ)。表示検証は `screen_text()` が VRAM を直接読むため、CRTC 初期化値そのものはエミュレータ表示には影響しない(=実機でのみ最終確認できる項目)。
