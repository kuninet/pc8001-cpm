# PC-8001 アトリビュート(VRAM 属性)構造

PC-8001 のテキスト VRAM は「表示文字エリア」と「アトリビュートエリア」が分離した**トランスペアレント方式**(μPD3301 ICW FORMAT5 = `0x53`)。色・反転・セミグラフィック等は後方のアトリビュートエリアで指定する。CP/M の `CONOUT` / `CLS`(`src/bios/bios.asm`)はこの構造に従って VRAM を書く必要がある。

## VRAM の 1 行構造(120 バイト)

```
+0          +80              +120
|  表示80B  | アトリビュート40B |  → 次の行は +120 から
```

- 表示エリア 80 バイト(`0xF300`〜):キャラクタコード。
- アトリビュートエリア 40 バイト(`+80`〜`+119`):2 バイト × 最大 20 組。
- 25 行 → 120 × 25 = 3000 バイト(`0xF300`〜`0xFEB7`)。

## アトリビュートの構成(2 バイト 1 組)

```
[ 左からの距離 ][ 表示属性 ]
```

- **第1バイト = 左からの距離**:`0x00`〜`0x50`(0〜80)。その桁から右へ属性が有効。
- **第2バイト = 表示属性**:下記の属性フラグ。
- 行内の**先頭組の距離は必ず `0x00`**(行頭がスタートライン)。
- 距離は右へ行くほど大きく(昇順)。最大 20 組。
- 使い切らない場合、残りは **`0x50, 0x00`** で埋めるのが安全(未初期化だと前行の色が残る等の誤表示)。

## 属性フラグ(カラーモード)

第2バイトのビット構成。`b3` がモードフラグ。

| ビット | モード1(`b3`=1) | モード0(`b3`=0) |
|--------|------------------|------------------|
| b7 | G(緑) | — |
| b6 | R(赤) | — |
| b5 | B(青) | 下線(UNDERLINE) |
| b4 | SG(1=セミグラフィック / 0=キャラクタ) | 上線(OVERLINE) |
| b3 | 1(モード1) | 0(モード0) |
| b2 | — | 反転(REVERSE) |
| b1 | — | 点滅(BLINK) |
| b0 | — | シークレット(SECRET) |

### モード1(色番号・セミグラフィック)

| 色 | 2進 | 16進 |
|----|------|------|
| 黒 BLACK | `00001000` | `0x08` |
| 青 BLUE | `00101000` | `0x28` |
| 赤 RED | `01001000` | `0x48` |
| 紫 MAGENTA | `01101000` | `0x68` |
| 緑 GREEN | `10001000` | `0x88` |
| 水 CYAN | `10101000` | `0xA8` |
| 黄 YELLOW | `11001000` | `0xC8` |
| **白 WHITE** | `11101000` | **`0xE8`** |
| セミグラフィック | `00011000` | `0x18` |

- `SG`(b4)= 0 でキャラクタ文字、1 でセミグラフィック(2×4 ドット)。**CP/M のテキスト表示では SG=0**。

### モード0(補助機能・組み合わせ可)

| 機能 | 16進 |
|------|------|
| 下線 UNDERLINE | `0x20` |
| 上線 OVERLINE | `0x10` |
| 反転 REVERSE | `0x04` |
| 点滅 BLINK | `0x02` |
| シークレット SECRET | `0x01` |

## CP/M での既定アトリビュート

CP/M コンソールは**白・キャラクタ表示**を既定とする。各行のアトリビュートエリア(40 バイト)は次で初期化する:

```
オフセット +80: 0x00, 0xE8,   ← 距離0 から「白・キャラクタ(0xE8)」
オフセット +82: 0x50, 0x00,   ← 残りは 0x50,0x00 で安全に埋める
オフセット +84〜+119: 0x50, 0x00, 0x50, 0x00 ...(または 0x00 詰め)
```

- 先頭 2 バイト `0x00, 0xE8` で行全体が白キャラクタになる。
- これを 25 行ぶん設定する。

## セミグラフィック(参考)

- キャラクタコード 0〜255 を 2×4 ドットに置換して表示(SG=1 のとき)。
- ビットとドットの対応: `b0`=LSB〜`b7`=MSB が各ドット位置(縦 4 × 横 2)。
- CP/M テキストでは使用しないが、将来の罫線/ブロック表示に利用余地あり。

## 実装メモ

- 現状 `src/bios/bios.asm` の `CLS` はアトリビュートエリアを **全 `0x00`** で埋めている。これは「距離0・属性0x00(モード0・補助機能なし)」となり、色やキャラクタ指定が不定になる恐れがある。本書の既定(各行 `0x00, 0xE8, 0x50, 0x00, ...`)へ修正する。
- `CONOUT` は表示エリア(各行先頭 80 バイト)へキャラクタを書くのみでよい(アトリビュートは行単位で `CLS` 時に設定済みのため)。
- 関連: CRTC ICW FORMAT5 は [CRTC初期化.md](CRTC初期化.md) を参照。
