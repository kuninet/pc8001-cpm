# ライセンス整理

関連issue: #14 / 親 #3
参照: `doc/設計/08_CPM取得ビルド.md`、`doc/設計/06_SDドライバ.md`、`doc/設計/09_開発環境.md`

## 1. 目的

本プロジェクトが利用・参照する外部成果物のライセンスを整理し、配布時の義務と
本プロジェクト独自成果物のライセンス方針を明確にする。

## 3. 各要素の留意点

### CP/M 2.2 本体
- 2022-07-07 に DRDOS, Inc.(Bryan Sparks 名義)が CP/M とその派生物の使用・配布・改変・改良を
  nonexclusive に許諾(原典: http://www.cpm.z80.de/license.html, `external/cpm22/LICENSE.txt`)。
- → **CP/M を含むブート用SDイメージの配布も可能**。ただし配布元(brouhaha/cpm22 等)の表記も尊重する。

### Z80 CPUコア(kosarev/z80, MIT)
- MIT のため利用・改変・再配布に制約なし(著作権表示の保持のみ)。
- 本リポジトリには同梱せず `external/` に取得(#12)。仮に同梱する場合も MIT 表示を保持すれば可。

### アセンブラ(asl, GPL-2.0)
- AS 本体は GPL-2.0。GPL の義務は **AS 自体(およびその改変版)の配布**に及ぶもので、
  **AS で生成した出力(本プロジェクトのBIOSバイナリ等)は AS の派生物ではなく GPL に縛られない**
  (コンパイラと同様)。
- 本プロジェクトは **AS を同梱せず**、利用者が各自で入手する前提(#9/#12)。よって GPL 義務は生じない。

### SD-DOS(chiqlappe/SD-DOS, ライセンス表記なし)
- 明示ライセンスが無いため既定で**全権利保有**。**ソースコードは流用しない**(#9 で独自実装)。
- 挙動理解のための**読解参考**にとどめる。SD SPI プロトコル自体は公開標準であり独自実装に問題なし。
- 任意で、作者(ちくらっぺ氏)へ参考/移植の**許諾を打診**する選択肢もある(得られれば幅が広がる)。

### ハードウェア(sdd / ram8k)・技術資料(ENRI氏)
- 基板のI/Oポート・配線、PC-8001 のメモリマップ/VRAM/I/O は**事実情報**であり、相互運用のために
  参照する。これらの**回路図・文章・図版そのものの転載や複製配布は行わない**。
- ENRI氏 の資料を参照した箇所は、本リポジトリのドキュメントで **「ENRI氏」** と敬称付きで出典を示す。

## 4. 本プロジェクト独自成果物のライセンス(方針)

対象: PC-8001向け **BIOS、ローダ、SD作成ツール、エミュレータのHW層、ビルド設定・スクリプト・ドキュメント**。

- **推奨: MIT ライセンス**(寛容・他要素と親和的。利用者の自由度が高い)。
- 確定はオーナー判断(現状 `README.md` は「未定」)。決定後に `LICENSE` を追加し README を更新する。

> 決定事項(要オーナー判断): 独自成果物のライセンス(MIT 推奨)。

## 5. 配布シナリオと義務まとめ

| 配布物 | 可否 | 根拠/義務 |
|--------|------|----------|
| CP/M を含むブート用SDイメージ | 可 | 2022 DRDOS 許諾。配布元表記を尊重 |
| 本プロジェクトの独自コード(BIOS/ツール等) | 可 | 採用ライセンス(MIT推奨)に従う |
| asl(アセンブラ)同梱 | しない | GPL回避のため同梱せず、入手先を案内 |
| kosarev/z80 ソース同梱 | しない(任意で可) | 同梱する場合は MIT 表示保持 |
| SD-DOS のコード | 不可 | ライセンス無し=流用不可。独自実装で代替 |
| ENRI氏資料/基板回路の転載 | しない | 第三者著作物。事実のみ参照 |
